# Provider ingest samples

## Files (FHIR resource per workbook)

| File | Endpoint | Order |
|------|----------|-------|
| `ng_provider_organization.xlsx` | `POST /v1/ingest/organization` | 1 |
| `ng_provider_location.xlsx` | `POST /v1/ingest/location` | 2 |
| `ng_provider_healthcareservice.xlsx` | `POST /v1/ingest/healthcareservice` | 3 |

Sheets are **A–Z + Others** by organization name. Each column holds FHIR-shaped JSON (or scalar) per the template headers.

## IDs (Postgres UUID)

Primary keys are **generated by Supabase** (`gen_random_uuid()`).

| Excel `id` / `identifier[].code` | Ingest behaviour |
|----------------------------------|------------------|
| Missing, label, or any **non-UUID** (e.g. `org-luth`) | **INSERT** new row → Postgres assigns UUID |
| Valid **UUID** | **VALIDATE** it exists, then **UPDATE** |

### Location

| `managingOrganization` | Behaviour |
|------------------------|-----------|
| Missing / non-UUID | **Skip** (orphan) |
| UUID | Validate org exists → then insert/update location by its own id |

### HealthcareService

| `location` | Behaviour |
|------------|-----------|
| Missing / non-UUID | **Skip** (orphan) |
| UUID | Validate location exists → set org from that location → insert/update service by its own id |

Workflow for an editable catalog spreadsheet:

1. Upload Organization sheet (codes like `org-luth` are fine) → copy org UUIDs from portal / job `ids`.
2. Put **Organization UUID** in Location `managingOrganization`; upload Location (orphans without org UUID are skipped).
3. Put **Location UUID** in HealthcareService `location`; upload services (orphans without location UUID are skipped).
4. Paste row UUIDs back into Excel for later **updates**.

Nearby projection: **`providers.id` = location UUID** (one map pin per Location). Mobile loads pins via `nearby_providers(lat,lng,…)` — it does **not** sync the full catalog into SQLite.

## Sample seed data

Placed on sheets **C / D / G / L / S**. First upload creates new UUIDs — copy them from the portal before Location / HS ingest or before re-upload updates.
